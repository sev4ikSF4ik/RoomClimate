# RoomClimate — програмна система інтелектуального моніторингу мікроклімату приміщення

Командний проєкт з дисципліни «Мультиплатформне програмування» (КНУ ім. Т. Шевченка, ФІТ, кафедра ПСТ).

Система збирає дані з сенсорів приміщень (температура, вологість, CO₂), зберігає їх,
аналізує й показує на веб-панелі: індекс комфорту, тренд CO₂, сповіщення про вихід
параметрів за межі норми та рекомендації («провітріть», «увімкніть зволожувач» тощо).

## Архітектура

```
┌──────────────────────┐   HTTP POST    ┌──────────────────────────────────────┐
│ RoomClimate.Simulator│ ─────────────▶ │ RoomClimate.Api (ASP.NET Core)       │
│ N сенсорів, кожен —  │ /api/readings  │  ├─ валідація                         │
│ окрема async-задача  │                │  ├─ Channel<Reading> (черга)          │
└──────────────────────┘                │  ├─ IngestService (фоновий потік):    │
                                        │  │    аналіз → сповіщення → SQLite    │
┌──────────────────────┐   HTTP GET     │  └─ REST API + статичні файли         │
│ Веб-панель (браузер) │ ◀───────────── │                                       │
│ wwwroot/index.html   │                └──────────────────────────────────────┘
└──────────────────────┘                          ▲ використовує
                                        ┌─────────┴────────────┐
                                        │ RoomClimate.Core     │  моделі, пороги,
                                        │ ClimateAnalyzer      │  індекс комфорту, тренд
                                        └──────────────────────┘
```

| Проєкт | Призначення |
|---|---|
| `src/RoomClimate.Core` | Доменна модель і логіка аналізу (без залежностей, легко тестується) |
| `src/RoomClimate.Api` | ASP.NET Core Minimal API, SQLite, фонова обробка, веб-панель |
| `src/RoomClimate.Simulator` | Консольний симулятор сенсорів з фізичною моделлю приміщення |
| `tests/RoomClimate.Tests` | Модульні тести xUnit |

### Використані технології

- .NET 10, C#, ASP.NET Core Minimal API
- SQLite (`Microsoft.Data.Sqlite`) — вбудована кросплатформна БД, індекси по `(room, ts)`
- Багатопотоковість: `Channel<T>` (producer/consumer), `BackgroundService`, паралельні `Task` + `PeriodicTimer` у симуляторі
- xUnit — модульні тести
- Docker / Docker Compose — контейнеризація
- GitHub Actions — CI на **Windows, Linux, macOS**
- Chart.js — графіки на веб-панелі

## Як запустити

Потрібен [.NET SDK 10](https://dotnet.microsoft.com/download). Працює на Windows, Linux і macOS.

```bash
# 1. Сервер (відкрийте http://localhost:5080)
dotnet run --project src/RoomClimate.Api

# 2. В іншому терміналі — симулятор сенсорів
dotnet run --project src/RoomClimate.Simulator -- http://localhost:5080 "Аудиторія 101,Аудиторія 202" 2
```

Аргументи симулятора: `[адреса API] [кімнати через кому] [інтервал у секундах]`
(або змінні середовища `API_URL`, `ROOMS`).

### Через Docker

```bash
docker compose up --build
```

Панель буде на http://localhost:5080.

### Тести

```bash
dotnet test
```

## REST API

| Метод | Шлях | Опис |
|---|---|---|
| GET | `/api/health` | Статус і ОС, на якій працює сервер |
| POST | `/api/readings` | Прийняти вимірювання `{room, timestamp, temperatureC, humidityPercent, co2Ppm}` |
| GET | `/api/rooms` | Список приміщень |
| GET | `/api/readings/latest` | Останні значення по кожному приміщенню + індекс комфорту |
| GET | `/api/rooms/{room}/readings?minutes=30` | Історія за період |
| GET | `/api/rooms/{room}/summary?minutes=30` | Аналіз: середні, індекс комфорту, тренд CO₂, рекомендації |
| GET | `/api/alerts?limit=50` | Останні сповіщення |

## «Інтелектуальна» частина

- **Валідація** — відкидаються фізично неможливі значення (збій сенсора).
- **Сповіщення** — два рівні (Warning / Critical) для температури (норма 20–24 °C),
  вологості (40–60 %) і CO₂ (> 1000 / > 1500 ppm).
- **Індекс комфорту 0–100** — штрафи за відхилення кожного параметра від норми.
- **Тренд CO₂** — нахил лінійної регресії (ppm/хв): зростає / спадає / стабільний.
- **Рекомендації** — формуються з середніх значень і тренду.
